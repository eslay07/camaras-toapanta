# Alternativa para Windows 7

Esta rama conserva la adaptación de Cámaras Toapanta PC v1.5.5 para Python 3.8 y Windows 7.

No es la línea oficial del proyecto. Se mantiene como variante histórica porque usa dependencias y pasos de instalación específicos para un sistema operativo sin soporte general. La rama `main` contiene la versión oficial.

El código procede del paquete local verificado `Camaras_Toapanta_PC_v1.5.5_Windows7_Python38.zip`. El ZIP y los ejecutables no se versionan; su integridad queda registrada en el inventario general.
