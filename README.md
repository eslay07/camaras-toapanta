# Cámaras Toapanta

Visor local de cámaras con dos clientes mantenidos en el mismo producto:

- `pc/`: versión oficial para escritorio, consolidada desde la fuente v1.5.5.
- `android/`: cliente Android independiente, consolidado desde la fuente v1.3.3.

La compatibilidad con Windows 7 no es oficial y se conserva en `codex/alternativa-windows-7`. Las direcciones, códigos y dispositivos incluidos en el código son ejemplos reservados; cada instalación debe usar su configuración local.

Consulta `PROVENIENCIA.md` para conocer la política de historial y `PASOS_GIT_GITHUB.txt` para validar y publicar.
